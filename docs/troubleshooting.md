# Running and troubleshooting Research Office

Run all npm commands from the repository root. Keep `.env`, `.env.local` and `data/` private. Use Node 24.14+ and Linux with Python 3.12+, Docker, Chromium, Tesseract English and Poppler. For Debian/Ubuntu, the operating-system packages are typically `python3-venv docker.io chromium tesseract-ocr tesseract-ocr-eng poppler-utils`; installation needs administrator privileges. Docker must be running and accessible to the trusted app host. Other operating systems may need Linux/WSL or a Linux VM for the validated execution environment.

| Symptom                                        | What to check                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm ci` fails                                 | Confirm Node version and registry/network access. Use the committed lockfile. In managed cloud environments keep the injected HTTPS proxy and CA trust; never disable TLS verification.                                                                                                                                                                                   |
| `setup` cannot generate Prisma clients         | Confirm all nine PostgreSQL URL settings are present after configuration is loaded. Local setup generates them automatically. Replace external placeholders and URL-encode passwords.                                                                                                                                                                                     |
| Python/OCR setup fails                         | Install Python venv support, Tesseract with English data and Poppler. Check `data/setup_review.log` only if you created that local log; normal setup logs to the terminal. OCR has an eight-page scanned-PDF limit per upload.                                                                                                                                            |
| Docker image preparation or code tests fail    | Check `docker info` on the trusted execution host and access to the image registry. Run setup to restore the digest-pinned runtime image. Never mount the Docker socket inside submitted code containers.                                                                                                                                                                 |
| Port already in use / database already running | Stop the previous `npm run dev` launcher with Ctrl+C before restarting. Do not launch two groups against the same `data/postgres`. Default ports are gateway 3000, domain services 4101–4109, agents 4201–4206 and local PostgreSQL 55432.                                                                                                                                |
| Prisma migration fails                         | Check database route, schema-creation/table DDL permissions and all nine service URLs. Migrations are transactional and checksum-checked. Do not edit applied SQL. Resolve permissions or add a new migration, then restart. Do not delete `data/` to hide a migration error.                                                                                             |
| Supabase is unreachable                        | Use a direct or session-pooler PostgreSQL URL from Supabase, not its HTTPS API URL or anon key. Select a route supported by your host's IPv4/IPv6 connectivity and firewall. Preserve verified TLS. `USE_EXTERNAL_DATABASE=true` requires every service URL.                                                                                                              |
| `.env` edit has no effect                      | Restart the launcher. Injected environment settings override `.env`; `.env` overrides generated `.env.local`. Check names/presence without dumping secret values. Quoted values can contain `#`; unquoted `#` starts a comment.                                                                                                                                           |
| Login rejected                                 | Use the effective `OWNER_PASSWORD`, at least 14 characters. Local setup generates one in `.env.local`. An override in `.env` or injected settings takes precedence. Cookie expiry requires signing in again.                                                                                                                                                              |
| Login works but writes fail with origin error  | Match `PUBLIC_ORIGIN` exactly to your browser's origin, including scheme/port and excluding a trailing slash. With production Secure cookies, serve HTTPS. Use the same hostname consistently.                                                                                                                                                                            |
| Azure 401/403                                  | Check the resource key and endpoint match and that Azure network policy permits this host. The browser never receives this key.                                                                                                                                                                                                                                           |
| Azure 404/400                                  | Use the documented base endpoint, deployment name, and a model compatible with system/user chat messages and `max_completion_tokens`. Role overrides fall back to `AZURE_AI_MODEL`. `/models` endpoints may need `AZURE_AI_API_VERSION`. Model availability and support vary.                                                                                             |
| Azure 429 / failed investigation               | Check quota/rate limits, context and token limits. Failed runs are retained and not silently retried. Reduce budgets or choose a compatible deployment and start a new run.                                                                                                                                                                                               |
| App still shows simulation                     | Set `RESEARCH_MODEL_MODE=azure`, endpoint, key and deployments, restart, then use `npm run check:connections -- --probe-models` to validate with six small paid chat calls. Simulation is fixed prose and cannot evaluate your research.                                                                                                                                  |
| Search/import fails                            | Brave discovery needs `RESEARCH_SEARCH_KEY`; live fallback searches Wikipedia snippets. Full text needs a public HTTPS source reachable under the environment allowlist. In proxy-only DNS environments approve the public hostname via `RESEARCH_SOURCE_DOMAINS` and network settings. No private IP targets, custom ports, authenticated downloads or paywall bypasses. |
| PDF/image export fails                         | Install Chromium or set `CHROMIUM_PATH`. Two exports can render concurrently; retry after an in-progress export finishes. Rendering blocks network access.                                                                                                                                                                                                                |
| Image generation fails                         | Configure the full `AZURE_IMAGE_ENDPOINT` with any required API version, compatible image deployment and Azure key. The provider must return base64 PNG data. Chat-model success does not validate images.                                                                                                                                                                |
| Old report omits a new comparison              | Reports snapshot comparison inputs at investigation time. Save the comparison first and run a new investigation. Separately appended project images/charts are labelled current at export time.                                                                                                                                                                           |
| Proposal has negative NPV or worse metrics     | Recheck matched scope, costs, revenues, units and evidence. Negative results remain visible. Revise the solution or pilot assumptions; the app cannot honestly establish an improvement without supporting evidence.                                                                                                                                                      |
| Phone cannot connect                           | This is server software. Deploy with HTTPS and a reachable private/owner-accessible origin; source on GitHub is not a running deployment. Internal service ports and the database must remain private. Offline mode supports notes, not server research.                                                                                                                  |

Useful checks:

```sh
npm run check:connections
npm run check:readiness
npm run build
npm test
```

Run fixture integration/browser suites only with a local development database and simulation mode. Back up the PostgreSQL database and retained document storage before infrastructure changes. Keep persistent `data/` on the same trusted host for this development launcher. Multi-host production requires service-specific storage, private routing, process supervision, backups and TLS termination; filling provider variables alone does not provision that infrastructure.
