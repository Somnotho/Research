# Release scope

The web application now implements the research workspace, specialist planning/review, bounded tools, document/OCR/version workflows, source imports, financial and decision analytics, scientific/formal checks, disposable implementation testing, report exports, diagrams, concept-image adapter, revocable private sessions and installable/offline shell.

## Connection tasks deferred by request

Supply Azure endpoint/deployments/key, optional image/Brave configuration and Supabase PostgreSQL connection strings through secure settings. Run live acceptance cases after connection. Actual Azure reasoning quality, model-specific request compatibility, live image output, broad search and Supabase connectivity cannot be established using dummy credentials. HTTP contract fixtures are labelled as fixtures.

## Deliberate boundaries

- No guarantee of exhaustive discovery, novel proofs, commercial benefit or physically valid innovation from arbitrary books.
- Formal checking covers the encoded linear-real-arithmetic claim. Symbolic identities apply where both sides are defined. Scientific/financial simulations retain assumptions; they are not physical experiments.
- Implementation containers test submitted standard-library Python prototypes. They do not change company infrastructure or execute physical experiments.
- OCR is English, with explicit page/size bounds. Unsupported formats must be converted; mathematical diagrams and OCR equations need human checking.
- Browser/PWA deployment is the current client target. Native app-store packaging, offline AI inference and enterprise multi-user administration are separate extensions.
- Knowledge retrieval is excerpt ranking with provenance. Neural embeddings, multilingual OCR, licensed market-data subscriptions and scheduled monitoring can be added as independent services if needed; none is represented as already verified.

These boundaries remain visible in the product so proposed evidence, computed results, provider output and unrun experiments are not confused.
